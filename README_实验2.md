# 实验二：软件设计与建模

项目：栖物——南京大学校园二手交易平台。学号241840080，朱爽爽。

## 成果

- `report/LaTeX版/report.tex`：报告源码；使用XeLaTeX编译两次更新目录。
- `report/LaTeX版/report.pdf`：报告编译结果，A4共13页。
- `report/LaTeX版/images/`：报告引用的6张矢量UML与14张UI图，均为外部插图。
- `design/设计说明.md`：数据、权限、状态转换、事务边界和需求追踪。
- `design/设计取舍.md`：候选方案、取舍理由及其代价。
- `design/UML/`：9组PlantUML图源、PNG和SVG。
- `design/UI/`、`design/UI源文件/`：页面及交互状态图、可编辑draw.io模型。
- `prototype/index.html`：本地浏览器交互原型，直接打开即可；页脚可重置数据和切换演示视角。
- `validation/`：原型交互、图稿渲染和报告编译的检查记录。

## 主要设计判断

接受预约与完成交易分别建模；主动下架可重提审核，违规下架还需解除重审限制；有效预约采用唯一约束，重复请求核对原结果；联系方式仅供当前已接受预约授权使用；交易页优先显示下一操作者和待办。具体理由、替代方案及边界见设计取舍文档。

## 验证范围

既有浏览器原型14项检查通过，覆盖预约、双确认、下架、超时、联系授权、审核和账号处理。截图与可编辑图稿完成渲染核对。报告由XeTeX引擎实际编译并逐页检查。

原型使用本地演示数据，不包含真实服务端权限、邮件、数据库事务或并发实现。上述后台能力及约100并发搜索目标将在实验3实现和验证。实验1需求基线为`lab1-final`，实验2新增提交在`lab2-submission`分支。

## 版本组织

本分支从实验1最终基线开始，依次提交领域模型与原型、设计取舍说明、报告与验证结果。AI工具使用与生成结果的修正记录见报告第四节，提交作者保留实际执行者信息。
