# LaTeX实验报告

`report.tex`为主文件，`images/`保存20张实际引用的外部插图（6张矢量PDF及14张UI PNG）。两者保持相对位置即可；正文没有TikZ、PGF、PSTricks或其他LaTeX绘图代码。

使用XeLaTeX连续编译两次：

```sh
xelatex -interaction=nonstopmode -halt-on-error report.tex
xelatex -interaction=nonstopmode -halt-on-error report.tex
```

推荐使用带中文支持的TeX Live。字体使用其自带的Fandol字体，不依赖本机安装的宋体。也可使用支持XeTeX的Tectonic。在线编辑器需选择XeLaTeX；上传源码及images文件夹后，以report.tex为主文档。

报告采用标准课程报告版式：居中课程标题、姓名学号、目录、中文大节编号、阿拉伯数字小节、图题及居中页码。章节按项目功能、设计模型、界面与验证组织。日期为本版整理日期2026年11月13日。
