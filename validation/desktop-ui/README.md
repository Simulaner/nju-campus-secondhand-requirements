# 栖物桌面界面验收

在独立的 SQLite 数据库中，用三个 Chrome 会话分别登录卖家、买家和管理员。公开大厅从空库开始，四件演示商品经管理员审核后上架。桌面截图来自 1440 × 940 浏览器窗口，同时在 1024 × 768 检查了大厅宽度。

| 页面 | 实测内容 |
| --- | --- |
| [空大厅](00-empty-market.jpg) | 访客可以从空大厅进入登录页，登录后继续发布。 |
| [商品大厅](01-marketplace.jpg) | 首屏展示最近上架的可预约商品，分类、价格组合查询和关键词搜索均返回预期商品。 |
| [发布页](05-editor.jpg) | 选择图片、输入名称、价格和地点时，右侧商品卡同步显示。 |
| [审核页](02-review.jpg) | 管理员审核通过后商品对买家可见。 |
| [详情页](06-detail.jpg) | 买家在价格和面交信息旁预约商品。 |
| [成交记录](03-completed.jpg) | 卖家接受、买家确认、双方确认三个时点，对应预约的成交记录数依次为 0、0、1。 |
| [管理工作台](04-management.jpg) | 交易结束后统计为商品 4 件、待审核 0 件、有效预约 0 笔、完成交易 1 笔。 |

运行 `make build test` 通过 80 项测试，`qa/check_races.py` 的 8 组并发检查通过。搜索压测使用 2,400 件样本商品，每轮 100 个并发请求，三轮共 300 个请求均在 2 秒内返回预期结果。
